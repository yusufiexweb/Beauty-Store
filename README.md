# Beauty Store // Cosmetic & Skincare E-Commerce UI

A high-performance, modern e-commerce landing page and UI ecosystem designed for beauty, skincare, and cosmetic products. Engineered with soft aesthetic color palettes, elegant product grids, and a lightning-fast responsive layout.

---

##  Key Architectural Features
- **Aesthetic Cosmetic Layout:** Clean, soft pink and elegant dark-mode balance tailored for beauty branding and conversion-focused product showcases.
- **Pure Vanilla JavaScript & Tailwind:** Zero heavy dependencies to guarantee maximum page speed and rapid DOM rendering.
- **Fully Responsive Layout:** Seamlessly optimized for mobile, tablet, and desktop viewports.

---

## Technology Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
